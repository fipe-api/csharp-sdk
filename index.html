C# SDK for the FIPE API

Fipe.Api.Br is a typed, async .NET client for querying average vehicle prices in the Brazilian market (Tabela FIPE) — cars, motorcycles and trucks — without writing any HTTP or JSON handling yourself.

.NET Standard 2.0 .NET Core / .NET 5+ .NET Framework 4.6.2+ MIT license

Install

Add the package from NuGet:

dotnet add package Fipe.Api.Br

Or via the Package Manager console: Install-Package Fipe.Api.Br

Quick start

Create a FipeClient and start querying. No configuration or token is required to get going:

using Fipe.Api.Br;

var client = new FipeClient();

var brands = await client.GetBrandsAsync(VehicleType.Cars);
foreach (var brand in brands)
{
    Console.WriteLine($"{brand.Code} {brand.Name}");
}

Vehicle types are an enum: VehicleType.Cars, VehicleType.Motorcycles and VehicleType.Trucks.

Getting a price

Drill down brand → model → year to reach a vehicle's average price:

var models  = await client.GetModelsAsync(VehicleType.Cars, "59");
var years   = await client.GetYearsAsync(VehicleType.Cars, "59", "5940");
var vehicle = await client.GetVehicleAsync(VehicleType.Cars, "59", "5940", "2014-3");

Console.WriteLine($"{vehicle.Model}: {vehicle.Price}");

If you already know a vehicle's FIPE code, skip the drill-down:

var vehicle = await client.GetVehicleByFipeCodeAsync(VehicleType.Cars, "005340-6", "2014-3");
var history = await client.GetHistoryByFipeCodeAsync(VehicleType.Cars, "005340-6", "2014-3");

foreach (var entry in history.PriceHistory)
{
    Console.WriteLine($"{entry.Month}: {entry.Price}");
}

Configuration

Authentication

The client works without a token on the free tier, which is rate limited. To use a subscription token:

var client = new FipeClient(subscriptionToken: "your-token");

Dependency injection

In ASP.NET Core or any host using IHttpClientFactory, register the client so the underlying HttpClient is managed for you:

services.AddHttpClient<FipeClient>();

// or construct it from a factory-created HttpClient:
var client = new FipeClient(httpClientFactory.CreateClient(), subscriptionToken: "your-token");

Reference months

Prices are published in monthly reference tables. Every method accepts an optional reference parameter to query a past month:

var references = await client.GetReferencesAsync(); // e.g. Code "308", Month "abril de 2024"

var brands = await client.GetBrandsAsync(VehicleType.Cars, reference: 308);

Client methods

All methods are async, return typed models, and take an optional reference month and CancellationToken.

MethodDescription
GetBrandsAsyncAll brands for a vehicle type
GetModelsAsyncModels of a brand
GetYearsAsyncYears available for a model
GetVehicleAsyncAverage price for a brand / model / year
GetYearsByBrandAsyncYears with published prices for a brand
GetModelsByBrandYearAsyncModels of a brand for a given year
GetYearsByFipeCodeAsyncYears available for a FIPE code
GetVehicleByFipeCodeAsyncAverage price looked up by FIPE code
GetHistoryByFipeCodeAsyncMonth-by-month price history for a FIPE code
GetReferencesAsyncAvailable monthly reference tables

Error handling

Non-success responses throw FipeApiException, which exposes the HTTP status code and response body. IsNotFound and IsRateLimited make the common cases easy to filter:

try
{
    var vehicle = await client.GetVehicleAsync(VehicleType.Cars, "59", "5940", "1900-1");
}
catch (FipeApiException ex) when (ex.IsNotFound)
{
    // unknown brand/model/year
}
catch (FipeApiException ex) when (ex.IsRateLimited)
{
    // back off, or use a subscription token
}
catch (FipeApiException ex)
{
    Console.WriteLine($"API returned {(int)ex.StatusCode}: {ex.Body}");
}

FAQ

Which .NET versions are supported?

The package targets .NET Standard 2.0, so it works on .NET Core, .NET 5 and later, and .NET Framework 4.6.2 or later.

Do I need an API token?

No — the SDK works without a token on the free tier, which is rate limited. Pass a subscription token to the FipeClient constructor to lift the limits. Tokens are issued by the FIPE API.

Is the client thread-safe?

Yes — FipeClient wraps a single HttpClient and can be registered as a singleton or typed client and shared across requests.

Where does the data come from?

Prices come from the FIPE API, which publishes the Tabela FIPE — average vehicle prices in the Brazilian market from Fundação Instituto de Pesquisas Econômicas, updated monthly.

Is there a runnable example?

Yes — the repository ships an example project: dotnet run --project examples/Fipe.Examples lists brands and prints a live price.
